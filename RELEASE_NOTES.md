# F-Zero: Maximum Velocity Recomp v0.1.0-preview

**Release Candidate 1 (`v0.1.0-preview-rc1`)**

Welcome to the initial preview release of **F-Zero: Maximum Velocity Recomp** for Windows x64!

---

## Highlights

- **Native Static Recompilation**: Recompiled from the original GBA binary into native x64 machine code using **GBARecomp v0.3.0**. No CPU emulation overhead during execution.
- **Official recomp-ui GUI Launcher**: User-friendly launcher integrated for ROM verification, BIOS setup, display scaling, audio volume control, and key binding.
- **Direct3D 11 Graphics**: Crisp 240x160 GBA rendering with integer scaling, sharp bilinear filtering, and full window resizing.
- **Faithful Mode 7 Simulation**: Accurate track rotation, perspective scaling, and high-speed course rendering.
- **Responsive Controls**: Fully native keyboard and SDL2 gamepad support with remappable bindings and custom drifting controls.
- **Battery-Backed Save System**: Standard 32 KiB SRAM persistence for Grand Prix cup records, best laps, and machine settings.
- **Verified Gameplay**: Validated playable title sequence, pilot selection, and Grand Prix race execution on Bianca City: Stretch Circuit.

---

## Getting Started

1. Unzip `FZeroMaximumVelocityRecomp-windows-x64-v0.1.0-preview-rc1.zip`.
2. Run `FZeroMaximumVelocityRecomp.exe`.
3. Provide your legally dumped copy of `F-Zero - Maximum Velocity (USA, Europe).gba` and authentic retail `gba_bios.bin`.
4. Click **PLAY** to start racing!

---

## Known Limitations

- **Preview Scope**: This candidate build focuses on core game mechanics, rendering, and single-player Grand Prix gameplay. Not all tracks or secret vehicles have been comprehensively playtested across a full championship.
- **No Multiplayer**: GBA Link Cable communication and multi-boot multiplayer modes are not supported.
- **ROM & BIOS Required**: Users must provide their own authentic ROM and retail BIOS files.
